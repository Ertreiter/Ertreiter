## About this site

**Phinisi Protocol.** The site opens on a full-screen 3D phinisi (the traditional ship of South Sulawesi) on a night sea made of moving code characters. Clicking "Set sail" or simply scrolling plays the same voyage: the ship fills its sails and sails over the horizon, then the 3D scene is torn down and the portfolio fades in, where a passport-style zero-knowledge developer ID verifies itself. Inside: experience as a logbook, projects with project-specific 3D hover illustrations, a skills dependency wheel where every skill is shown by its logo, and a Ctrl+K command palette.

Static site, no build step: HTML, CSS and ES modules with [Three.js](https://threejs.org/) and [anime.js](https://animejs.com/) from CDNs. Visitors can skip the intro (button, scroll, Enter), deep links skip it automatically, and it is skipped for `prefers-reduced-motion` or browsers without WebGL.

Skill logos come from [Simple Icons](https://simpleicons.org/) (CC0) and concept icons from [Lucide](https://lucide.dev/) (ISC); see `js/skill-icons.js`.

To preview locally, serve the folder over HTTP:

```
python -m http.server 8000
```
